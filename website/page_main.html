    Design together with an AI

    Everything you can click, you can type — and everything you can type, a script or an AI agent can do. Automate with the JavaScript console, visual node graphs and plugins, or connect Claude and other agents through the built-in Model Context Protocol server.

    archi-cli --mcp ~/Documents/house.archi

    JavaScript console
    // A row of houses, each one a real building element
for (let i = 0; i < 4; i++) {
  const x = i * 14000
  const w = [[x,0],[x+10000,0],[x+10000,8000],[x,8000]]
  w.forEach((p, k) => archi.wall(...p, ...w[(k+1)%4], { height: 3200 }))
  archi.slab(w, { thickness: 250 })
  archi.addElement({ type: "roof", boundary: w, kind: "gable", pitch: 35 })
}
archi.run("ZOOM E")

    A few useful details

    Before you begin

    Is it really free?

    Yes. Oanarina Archi Tool is free software under the GNU General Public License 3.0: no account, no subscription and no watermark.

    Can I open my AutoCAD, Revit or SketchUp work?

    Open and save DXF, the exchange format AutoCAD, LibreCAD and most CAD tools read and write; save DWG files as DXF first. Exchange building models as IFC with Revit, ArchiCAD and other BIM tools. Rhino 3DM files open directly; SketchUp files open through a free converter.

    Does it work offline?

    Yes. Drawings and models stay on your Mac. The optional agent server listens only on your own computer and is off until you turn it on.

    How complete is it?

    {{FEATURES}} of the {{TOTALFEATURES}} capabilities in the public feature register are built and tested. The remaining ones are marked openly in the register, most of them waiting for outside validation.

    Who makes Oanarina Archi Tool?

    Oanarina Archi Tool is developed by Oana Rinaldi, with ideas drawn from the open-source FreeCAD, LibreCAD, IfcOpenShell, SolveSpace, OpenSCAD, BRL-CAD, Sverchok and CAD Sketcher communities.

    How can I share feedback?

    Report a reproducible problem or suggest an improvement through the contact page. Include your macOS version and the steps that led to the problem.
